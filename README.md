# URL Xtracter
Extract 99% of all URLs present in any complicated string using regex.

URLs can be complicated strings: there are 1000+ common TLDs and, on top of that, a staggering number of unregulated domains. If we talk about tiny URLs, the number skyrockets. This code snippet will help extract 99% of the URLs from any string using regex, including complex URLs. 

You can contribute to it to further enhance its regex check, or please suggest a case it doesn't handle.
